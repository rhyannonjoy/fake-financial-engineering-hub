# AI-Assisted Statement

![Computer speaks rainbow sparkles with text "human-authored, AI-assisted"](../static/img/human-authored-ai-assisted.png)

is based on real docs from my time as a fullstack engineer and de facto
docs guy in a variety of technical contexts. Much of the original content
these versions are based on was written without any AI. While I have lots
of experience using a variety of tools during the entire software development
lifecycle, this project is specifically assisted by [Claude](https://claude.ai/).

the editorial decisions and bad jokes are unfortunately mine.
